# 微信机器人自动回复

个人微信自动回复助手：学习登录用户的回复习惯，模拟本人延迟思考后，以本人身份自动回复。SwiftUI 原生界面（西瓜狗风格），Rust 运行时（裁剪自 [微信机器人框架/zmybot](../微信机器人框架/)），wxbot（iLink）手机遥控。

## 核心能力

- **消息中心**：会话列表（勾选/批量/搜索）、气泡对话、文本/图片/文件收发
- **数字分身**：解密本机微信本地库导入历史会话做画像基线，双层习惯引擎（本地统计画像 + AI 蒸馏摘要），人设卡，人类节奏（正在输入 + 随机延迟）
- **三档模式**：观察（默认）→ 建议 → 全自动，手机指令随时叫停
- **AI 可切换**：自家中转站 / DeepSeek / Kimi / Qwen / OpenAI（OpenAI 兼容）；jev 判断模型固定走自家中转站
- **两种运行模式**：云端 AI 模式（脱敏后发上下文，明示告知）/ **本地规则模式**（零外发，**不跑本地模型**，走规则库+技能库直答）
- **wxbot 遥控**：腾讯官方 iLink Bot API 长轮询，手机指令暂停/查询/代回复/审建议卡
